---
name: blog-post
description: Research and write a search-friendly blog post that answers one question well.
---
1. Pin down the reader's question and the search term. Search it and read the top 3 results; note what they miss.
2. Outline: a title with the term, a two-sentence answer up top, 4–7 sections that follow the reader's next questions, and a closing call to action that fits the company.
3. Write it at 900–1500 words unless told otherwise. Short paragraphs, concrete examples, sources linked inline.
4. Add a meta description (under 155 chars) and 3 title alternatives.
5. Save as drafts/<slug>.md.

argument-hint: "<idea, link or file to repurpose>"

1. Pull the single strongest insight and 2–3 supporting points from the source.
2. Read `references/platform-limits.md` and size every piece to it.
3. LinkedIn: hook line, short story or proof, the takeaway, a question to invite replies.
4. X: one post, plus a 5–7 post thread version.
5. Instagram: carousel outline (slide by slide) and a caption.
6. Short video (Reels/Shorts/TikTok): hook in the first 2 seconds, beats with on-screen text, spoken lines, closing call to action.
7. If you have the generate_image tool and the user wants visuals, use the post-visuals skill for the carousel cover.
8. Save everything in one file drafts/social-<slug>.md, one section per channel.

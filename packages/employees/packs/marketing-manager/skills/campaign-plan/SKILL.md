---
name: campaign-plan
description: Turn a goal ("more sign-ups for X") into a concrete campaign with channels, messages, assets and metrics.
---
1. Restate the goal as a number and a date. If neither was given, propose them and say so.
2. Define the audience segment and the one problem they have that we solve. Pull from memory; research if missing.
3. Pick at most 3 channels and justify each by where this audience already is.
4. For each channel: the message angle, the assets needed, the call to action, the budget or effort, and the metric that proves it worked.
5. Draft a two-week timeline.
6. Brief the Content Creator for the first assets (send_to_teammate) with audience, angle, format and length.
7. Save the plan as plans/<campaign>.md.

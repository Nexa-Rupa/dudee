---
name: competitor-watch
description: Check what competitors changed (pricing, positioning, launches, content) and what it means for us.
---
1. List competitors from memory. If there are none, search for "<our category> alternatives" and "<our product> vs", pick the 3–5 most relevant, and save them with memory_save.
2. For each competitor, fetch the home page, pricing page and blog or changelog.
3. Compare with what you remembered last time (memory). Note only real changes: new pricing, new plans, new headline or positioning, launches, big content pushes.
4. Write the report with these sections: Changes (per competitor, with links) · What it means for us · Recommended actions (max 3, each with owner and effort).
5. Save the report with files_write, and save each competitor's current pricing and headline with memory_save so next week's run can diff against it.

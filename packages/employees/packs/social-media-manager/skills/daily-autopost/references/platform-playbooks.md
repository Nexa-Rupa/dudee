# Posting through the browser, platform by platform

Sites change their layouts. Always take a `browser_snapshot` and act on what is there, not on these notes.
Upload files with `browser_file_upload` and the full paths `social_publish_request` gave you. After any upload,
wait (`browser_wait_for` 3-10 seconds, longer for video) until the preview shows before you continue.

## X (Twitter)
- Sign in: x.com/i/flow/login → username field → Next → password → Log in. A code prompt: `vault_fill` field `otp`.
  An "unusual activity" prompt may ask for the phone or email: ask_user.
- Post: x.com/compose/post → type the text into the "Post text" box → the media button (picture icon) opens a
  file input → upload → wait for the preview → "Post".
- URL: open the profile, the newest post, copy the address (x.com/<handle>/status/<id>).

## LinkedIn
- Sign in: linkedin.com/login → email → password → Sign in. Verification codes go to email: ask_user.
- Post: linkedin.com/feed → "Start a post" → type the text → the media icon to add an image or video → Next →
  "Post". For a company page, open the page admin view first and post as the page.
- URL: the post's "…" menu → "Copy link to post".

## Instagram
- Sign in: instagram.com/accounts/login → username → password → Log in. "Save login info": choose Not now or Save.
- Post: the "+" (Create) in the sidebar → Post (or Reel for video) → "Select from computer" → upload → Next
  (crop: keep the original) → Next → write the caption → Share. Reels: 9:16 video.
- URL: the profile → newest post → copy the address (instagram.com/p/<id> or /reel/<id>).

## Facebook (Page)
- Sign in: facebook.com/login → email → password. Switch to the Page profile if the account manages one.
- Post: the Page → "What's on your mind?" → text → Photo/video → upload → Post.

## Threads
- Sign in with the Instagram login on threads.net/login.
- Post: the compose button → text → the attachment icon → upload → Post.

## YouTube (Shorts or video)
- Sign in through accounts.google.com (Google may ask for a code or a phone tap: ask_user).
- Post: studio.youtube.com → Create → Upload videos → select file → title (`title` from the request) and
  description (the approved text) → "No, it's not made for kids" → Next ×3 → Public → Publish.
  A vertical video under 60 seconds becomes a Short.

## TikTok
- Sign in: tiktok.com/login → "Use phone / email / username" → log in with password.
- Post: tiktok.com/tiktokstudio/upload → select video → caption → Post. TikTok checks content for a while;
  the URL appears on the profile once it is processed.

## Reddit
- Post only to communities the brief names, and follow each community's rules. reddit.com/submit → choose the
  community → title → body or media → Post.

## Pinterest
- pinterest.com/pin-creation-tool → upload the image or video → title, description, link → board → Publish.

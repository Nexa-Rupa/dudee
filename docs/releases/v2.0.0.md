The first open-source release of **dudee**: AI employees you run yourself, with your own model keys.

## Install

```bash
npm install -g dudee
dudee init
dudee ui
```

Or with Docker:

```bash
docker run -d -p 127.0.0.1:4777:4777 -v dudee-data:/data --env-file .env -e DUDE_UI_TOKEN=<long-random-string> ghcr.io/nexa-rupa/dudee:2.0.0
```

## What's in it

**Ready-made employees**
- Marketing Manager, Content Creator, Calling Agent and Research Analyst, each with a role, step-by-step skills, tools, memory and files
- Hire in seconds from the web app or `dudee hire <role>`

**A team board you can trust**
- Live status for every employee: working, needs you, idle, paused
- Every step shown as it happens, with how long it took
- Approvals for anything that sends, posts, schedules, calls or spends: Allow, Always allow, Don't allow (and take "always" back later)

**Bring any model**
- Anthropic (Claude), OpenAI (GPT, Codex), Google (Gemini), Groq, OpenRouter, DeepSeek, Moonshot (Kimi), Z.ai (GLM), Qwen, xAI, Mistral, Together, Fireworks, Cerebras, Ollama, LM Studio, 9router, or any OpenAI-compatible endpoint
- A different model per employee; keys stay on your machine

**Built on open standards**
- Skills in the Agent Skills format (`SKILL.md`), shared with Claude Code and Codex; run one with `/name`
- Apps over MCP (GitHub, Notion, Slack, Composio and more)

**Running a team**
- Monthly budgets per employee and per team, with a note at 80% and an automatic pause at 100%
- Pause and resume, company goals, routines with "Run now" and a webhook
- Export and import a whole team (never keys)
- Each Marketing Manager and Researcher gets their own browser; the Content Creator makes images and video through fal.ai; the Calling Agent calls through your own Vapi account

**Self-hosting**
- One npm package (`dudee`), Node.js 22.13 or newer
- Docker image and `docker-compose.yml`; data in a volume, listens only on localhost until you open it up

## Upgrading from dudee 1.x

dudee 2 replaces the 1.x "Company Brain". It stores its data in `.dude/` and does not touch `~/.dudee/`.

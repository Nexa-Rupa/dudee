**dudee 2.2.1** makes budgets work with OpenRouter models. Before, every OpenRouter model counted as unpriced, so spend showed $0.00 and a budget couldn't stop anything until you typed prices in by hand.

## Install or upgrade

```bash
npm install -g dudee@2.2.1
dudee ui
```

Your workspace (`.dude/`) carries over.

## What's fixed

- **OpenRouter prices are fetched for you.** Before a task on an OpenRouter model with no price, dudee reads OpenRouter's public price list (no key is sent) and saves it in `.dude/provider-prices.json`. It refreshes the list once a day in the background. Prices you set in Settings still win.
- **Budgets on OpenRouter models count and pause** employees at their limit, like other priced models. If the price list can't be reached, a budget still asks you to set a price, as before.
- **Settings → Model prices** shows OpenRouter's price for the models in use.
- **Spend under a cent shows its digits** (`$0.0016`, not `$0.00`) in the web app, `dudee budget`, and the budget notices.

Tasks run before upgrading keep the cost they were recorded with.

**dudee 2.2.0** gives you more control over work in progress (stop, steer, attach files, fall back to another model) and closes a set of safety and reliability holes. Upgrading is recommended, especially if you use saved logins or autopost.

## Install or upgrade

```bash
npm install -g dudee@2.2.0
dudee ui
```

Your workspace (`.dude/`) carries over; new tables and columns are added in place.

## What's new

**Control**
- **Stop** an employee mid-task (also `/stop Maya` in Telegram). Open cards close, and teammates working on that task stop too
- **Steer**: a message sent while they work is read at the next step
- **Attachments**: pick, drop or paste files in chat. Pictures and PDFs go to models that can read them; images, video and audio open in Files

**Models and cost**
- **Fallback models**: when a model fails or hits a limit, the next one carries on from the last finished step
- A **model per routine**
- Claude prompt caching, priced at cache rates; old browser pages are dropped from long tasks
- With more than 25 app tools, employees search for the one they need

**Routines, memory and work**
- A **webhook address per routine** that opens nothing else, and **run history**
- **Edit memory** in the app, and **team memory** every employee reads
- An **open work** list per employee
- Employees can **save skills** for the team, with your OK

## Security fixes

- Saved logins are typed only on the account's own https site, and passwords only into password fields of the page itself. (Typing a saved login did not work at all in 2.1.0.)
- Approving one post no longer allows every browser and app action for 20 minutes: it covers that account's site, the approved text and the approved files
- `web_fetch` reads public addresses only, checked when connecting and on every redirect
- Commands and video renders no longer inherit your API keys, and known keys are scrubbed from tool output
- Importing a team file never grants "always allow"
- The MCP client is updated to 1.32.2, which no longer re-sends headers when a server redirects elsewhere

## Reliability fixes

- Earlier messages stay in the conversation however many steps a task took
- Employees who ask each other at the same time no longer wait forever
- Unanswered approvals from scheduled work expire after 30 minutes (`approvalTimeoutMin`)
- Budgets stop a task partway, and failed tasks count
- Memory never drops old notes silently

## Things that may need a change

- With a budget set, a model with no known price is refused until you add its price in Settings (0 if it's free)
- Skill scripts that need a key must be listed in `DUDE_SHELL_ENV`, e.g. `MY_TOOL_TOKEN`
- To let employees read local or intranet pages, set `DUDE_ALLOW_PRIVATE_FETCH=1`
- "Post without asking" accounts ask again if the employee types anything beyond the approved text
